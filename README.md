# Music Lab

Music Lab is an offline-first tool for making electronic music by assembling and shaping musical ideas. The working name is provisional.

The first milestone is a Mac-first prototype: choose and vary preset parts, arrange them into a short song, save the project and render audio. An iPhone experience is a future target, not a requirement for the first prototype.
