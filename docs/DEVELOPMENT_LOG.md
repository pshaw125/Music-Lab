# Development log

Broad milestones, decisions and changes of direction belong here. Keep detailed current tasks in [ROADMAP.md](ROADMAP.md).

## 2026-11-24 — Project direction and initial documentation

- Established Music Lab as a working name for an offline-first electronic music composition tool, inspired by Figure, Punk-o-matic and Strudel.
- Defined four levels of composition, prioritizing song arrangement and preset-based parts for v0.1. Individual note and rhythm editing, and deep sound design, follow later.
- Chose Mac as the first development target, with iPhone deferred. TypeScript and Web Audio/Tone.js are candidates for an initial feasibility spike rather than settled implementation decisions.
- Specified shared-part edits and save-as-new behavior, with an optional replacement in the current project. Exact replacement scope remains open.
- Emphasized tactile controls and expressive preset macros that can eventually expose underlying parameters.
- Recorded an offline asset requirement and the need to evaluate sound/effect libraries and redistribution rights.
- Attempted `git init`; the execution environment denied creation of `.git`. Repository initialization and the initial commit remain to be performed locally.
